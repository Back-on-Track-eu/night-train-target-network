# Feedback

This is a model of a network that does not exist yet, built in the open and
still being corrected. Most of what improves it arrives from outside: a
station the catalogue never had, a charge that is out of date in one country,
a formula that holds everywhere except the one case you work in.

Everything sent here reaches the target network working group, with your
address as the reply-to. Say what kind of feedback it is so it lands with the
person who can act on it — the categories come from the model itself, so
"Infrastructure" lists the parameters you can actually challenge, and
"Evaluation — calculation method" lists the cost and revenue components by
name.

If the correction is about one page of this documentation, the short form at
the foot of that page is quicker: it carries the page with it.
